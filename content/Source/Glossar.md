
| Begriff                            | Definition                                                                                                                                                                                                                                     |
| :--------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Annuität**                       | Die regelmäßige jährliche Zahlung, die sich aus Zins und Tilgung zusammensetzt.                                                                                                                                                                |
| **Autokredit**                     | Bei dieser Kreditart wird das Auto als Sicherheit behalten, das im Falle eines Zahlungsausfalls gepfändet wird.                                                                                                                                |
| **Beschränkte Geschäftsfähigkeit** | Minderjährige zwischen 7 und 18 Jahren benötigen die Erlaubnis ihrer gesetzlichen Vertreter, um wirksam Rechtsgeschäfte tätigen zu können.                                                                                                     |
| **Bürgerliches Gesetzbuch (BGB)**  | Das Gesetzbuch regelt das bürgerliche Recht, also die allgemeinen Rechtsbeziehungen von Personen oder Gesellschaften untereinander. Es beinhaltet z.B. Regelungen über die Wirksamkeit von Rechtsgeschäften (Geschäftsfähigkeit) und Verträge. |
| **Dispositionskredit**             | Wer sein Konto überzieht (ins „Minus“ geht), nutzt automatisch diesen in der Regel teuren Kredit.                                                                                                                                              |
| **Effektivzins**                   | Dieser bezeichnet die jährlichen, auf die Kredithöhe bezogenen Kosten eines Kredits.                                                                                                                                                           |
| **Geschäftsfähigkeit**             | Wer diese besitzt, darf Rechtsgeschäfte selbstständig und vollgültig abschließen.                                                                                                                                                              |
| **Geschäftsunfähigkeit**           | Tätigt ein Minderjähriger unter sieben Jahren oder ein Geisteskranker ein Rechtsgeschäft, so ist dieses nichtig.                                                                                                                               |
| **Gesetzliche Vertreter**          | Die durch das Gesetz bestimmten Vertreter für eine Person, die nicht in der Lage ist, für sich selbst rechtsgeschäftlich tätig zu sein (z.B. Eltern, Vormunde, Betreuer).                                                                      |
| **Gläubiger**                      | Juristisch betrachtet ist ein Gläubiger jemand, der aufgrund eines Schuldverhältnisses berechtigt ist, von einer anderen Person (dem Schuldner) eine Leistung zu fordern (§ 241 BGB).                                                          |
| **Inkassounternehmen**             | Diese Unternehmen treiben eigene Forderungen oder Forderungen ihrer Auftraggeber ein.                                                                                                                                                          |
| **Konsumentenkredit**              | Ein Kredit für eine bestimmte Anschaffung durch den Verbraucher.                                                                                                                                                                               |
| **Kreditkarte**                    | Bei einer Kreditkarte werden alle Zahlungen einmal monatlich vom Konto des Inhabers abgebucht. In dieser Zeit fallen keine Zinsen an.                                                                                                          |
| **Peer-to-Peer-Kredit**            | Kredite, die nicht von Banken, sondern von Privatpersonen vergeben werden, z.B. über das Internet. Die Bedingungen können individuell abgestimmt werden.                                                                                       |
| **Rahmenkredit**                   | Innerhalb eines vereinbarten Kreditrahmens können die Kreditnehmer beliebig viele Beträge abrufen und auch beliebig oft und viel tilgen.                                                                                                       |
| **Ratenkredit**                    | Diese Kreditform zeichnet sich dadurch aus, dass sie monatlich in festen Raten zurückbezahlt wird.                                                                                                                                             |

| **Restschuldenbefreiung**          | Sie steht am Ende des Verbraucherinsolvenzverfahrens und wird eingeleitet, wenn trotz Schuldnerberatung keine außergerichtliche Einigung mit den Gläubigern erzielt werden konnte.                                                             |
| :--------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Schuldnerberater**               | Diese helfen dem Schuldner, einen Überblick über seine Finanzen zu verschaffen, beraten bei der Reduzierung von Ausgaben und der Erhöhung von Einnahmen und unterstützen bei Verhandlungen mit Gläubigern.                                     |
| **Schwebend unwirksam**            | Ein Rechtsgeschäft, das von einem beschränkt Geschäftsfähigen getätigt wird, ist so lange „schwebend unwirksam“, bis es vom gesetzlichen Vertreter genehmigt wird und damit rechtskräftig wird.                                                |
| **Tilgung**                        | Die planmäßige Rückzahlung von Schulden.                                                                                                                                                                                                       |
| **Verbraucherinsolvenzverfahren**  | Dieses gerichtliche Verfahren soll die Bewältigung der Zahlungsunfähigkeit von Privatpersonen leisten, sie also von Schulden befreien.                                                                                                         |
| **Volljährigkeit**                 | Tritt mit der Vollendung des 18. Lebensjahres ein. Das elterliche Sorgerecht und die Vormundschaft enden dann, und man ist vollständig geschäftsfähig.                                                                                         |
| **Wohlverhaltensphase**            | Phase im Verbraucherinsolvenzverfahren, in der der Schuldner die pfändbaren Teile seiner Einnahmen an einen Treuhänder abgeben muss, um seine Schulden zu tilgen. Nach 6 Jahren werden bei Erfüllung aller Auflagen die Restschulden erlassen. |
